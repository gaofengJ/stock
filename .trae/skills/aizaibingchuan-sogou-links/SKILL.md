# 爱在冰川搜狗微信链接发现

只使用搜狗微信搜索发现链接；一次只处理一个四位自然年。

- 搜索入口：`https://weixin.sogou.com/`
- 预期账号名：`爱在冰川`

## 边界

- 只把搜狗微信结果页作为链接发现来源；不得改用雪球、新榜、普通网页搜索、微信公众号历史页、隐藏接口或第三方转载站补全结果。
- 只收集结果卡中可见的标题、公众号名、发布时间和原文 URL。不得读取文章正文、图片、评论或账号资料。
- 只接受卡片直接给出的 `https://mp.weixin.qq.com/s/...` URL。若链接是不可解析的搜狗跳转地址，记录为“URL 未解析”，不要访问目标文章。
- 不覆盖 `source-links-<YYYY>.md`，也不运行文章入库 Skill。候选清单必须由用户确认后，才能提升为入库输入。

## 搜索与分页

1. 打开搜索入口并快照；在搜索框输入 `爱在冰川 <YYYY>`，选择“搜文章”。
2. 每次页面变化后重新快照。遍历结果页与“下一页”，直到没有下一页、结果重复或搜索站点明确限制分页。
3. 仅保留公众号名明确为“爱在冰川”、页面展示发布时间属于目标年的结果。标题或摘要中出现年份不能替代页面发布时间。
4. 以规范化后的原文 URL 去重。相同 URL 只保留一次；同日多篇按搜狗展示顺序保留。
5. 搜狗搜索本身可能不保证全量收录。不得把“结果数”声称为该年份全部文章数。

## 访问限制

出现滑块、验证码、反爬提示、登录提示或“访问异常”时立即暂停，告知用户在当前可见浏览器完成验证后回复继续。

- 不解验证码、不模拟滑块、不轮换代理、不保存或输出 Cookie、密码、验证码、会话状态。
- 用户未完成验证时，写候选清单中的限制说明；不要把受限结果写成零篇。
