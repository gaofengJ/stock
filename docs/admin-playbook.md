# 管理员交易与学习体系

独立入口 `/trading-system/`（顶部导航“交易体系”） 提供四张导图，支持展开、缩放、搜索、体系正文和本地 XMind 导出。导出使用浏览器内存，不发送到第三方服务；目前不支持拖拽编辑或导入。

## 私有内容与权限

本仓库公开，因此仅存放展示器、接口与合成测试数据。真实正文不提交 Git，不进入镜像构建上下文、前端静态产物、博客或公开 CI 构建附件。正文使用去个人化的规则，不包含身份、家庭资产、账号、持仓、交割单或原始截图。

部署由 GitHub Actions Secret `ADMIN_PLAYBOOK_GZIP_BASE64` 注入：值为 UTF-8 JSON 经 gzip 压缩后的 Base64。仅部署任务将其写入权限 600 的服务器运行配置，沿用现有只读挂载。构建与测试不读取此 Secret。内容更新时更换 Secret 并重新部署后端，禁止在日志中打印明文或编码值。

`GET /api/admin/playbook` 先经全局 AuthGuard 验证当前会话、账号状态与改密要求，再检查内置 `admin` 角色。匿名和游客返回 401，普通用户与委派管理权限用户返回 403；响应 `Cache-Control: no-store`。缺失或损坏配置返回不含原始内容的 503。所有真正的管理员均可阅读和导出，需妥善保管下载文件。

无需数据库迁移。发布冒烟检查验证管理员获得四张图、未登录请求被拒绝。后端权限测试还覆盖角色撤销与强制改密；前端测试覆盖路由边界、搜索和 ZIP/XMind 结构。静态导出检查防止正文混入公开产物。XMind 文件结构经过测试，原生客户端兼容性尚未人工验证。

## 晚间执行入口（2026-10-11）

每日复盘的管理员笔记统一为市场、持仓与执行、候选、明日计划四步。每步展示问题、记录出口与数据入口；上次计划放在持仓与执行中默认展开。辅助工具保留观察名单和持仓分析，带回的快照用于私人笔记。观察名单的容量不等于待触发交易数量。

交易体系只提供规则与方法，并链接每日复盘。管理员导图正文仍经私有配置部署，不写入公开仓库。私人笔记字段及服务端历史版本保持兼容。

文章整理在复盘后进行；两渠道预览与发布快照采用相同的四块公开文章结构。调用说明按钮仅复制指定日期的 Skill 请求，不会在网页后台运行 Skill 或创建飞书文档。个人 Skill 和飞书目录配置保存在用户本地，不进入网站包。
