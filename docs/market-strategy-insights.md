# 市场与策略观察

## 页面入口与口径

- 大盘概览：新高／新低家数和占比，跟随本页交易日、统计范围，支持 20／60 日和名单查看。以复权收盘价严格突破此前 N 个交易日收盘价高低为准；相等不算突破。分母是当日有成交且历史完整的股票，包含 ST，历史不足不按零计。
- 策略选股 → 横向比较：对当前候选股比较 20／60 日涨幅、全市场 RPS 百分位、同花顺行业超额涨幅、多策略交集及人气排名。行业超额单位为百分点，行业成分基准日期可查看；行业归属不唯一或价格不足时留空。
- 策略选股 → 信号后续表现：按各策略标准参数统计近 20／60 个交易日信号，观察信号日复权收盘至后 1／3／5／10 个交易日复权收盘的涨跌。展示均值、中位数、上涨占比、有效样本、未到期和数据不足数量。同股不同日期分别计样本，不含交易成本，不等于可成交的策略回测收益。不跟随自定义参数。行业／题材筛选只使用信号日已存在的成分快照；没有历史成分则该日不纳入统计。
- 策略选股 → 同花顺人气变化：全市场热股日终 Top100，与上一交易日比较名次，提供上升／下降、新上榜／离榜及近 20 日排名趋势。仅使用日终记录；缺榜不以更早日期代替。接口不足 100 条时展示实际条数，只比较已知名次，不把缺位判为新上榜或离榜。

## 数据与运行

新增迁移 `MarketInsights1791590400000`，只创建两个表，不重建已有行情表：

| 表 | 用途 |
| --- | --- |
| `t_processed_stock_insight` | 按交易日存储复权价格、RPS、新高／新低汇总与九种标准策略信号快照 |
| `t_source_ths_hot` | 按交易日保存同花顺日终热股榜单及榜单时间 |

复用现有行情、复权因子、同花顺行业成分和行业日线。信号快照记录规则版本及参数，源行情、因子或删除策略变化后旧快照失效并重新计算。读接口不触发重计算或 Tushare 抓取。

部署及日常同步加入现有后台队列 `insights` / `hot`，默认补齐最近 60 个交易日，分批处理，每批最多 3 日；工作日晚 22:40 补录日终人气。历史日期同步不会扩大自动补齐窗口。任务遵守全站同步锁、主动删除保护和失败重试规则，状态可在管理后台查看。新高／新低需要前置 61 日复权数据；九种标准策略沿用各自的历史要求。

历史表现接口只读取必要的收盘与信号字段，并按日期、股票建立查找索引；明细使用虚拟滚动，避免一次渲染数万行。所有统计严格截止所选日期，缺失保留空值，北交所代码变更沿用已有复权衔接口径。

历史日终人气接口返回空快照时，该日保留缺口、24 小时后重试，并继续补齐其他日期。不会用盘中记录冒充日终榜单，也不会将空榜视作所有股票离榜。管理后台任务保持待补状态，直到源端返回有效日终记录。
