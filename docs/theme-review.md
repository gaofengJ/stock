# 题材复盘

入口为市场分析 → 涨停复盘 → 题材复盘，与原有页面共用日期、统计范围、行业／概念、股票搜索和连板筛选。使用现有表格、详情抽屉、来源状态、明暗主题及权限 `analysis:limits`。

## 数据口径

- 股票范围来自既有非ST涨停名单；题材和原因通过 Tushare `kpl_list` 的当日涨停记录补充。当前账户可访问该来源，同花顺 `limit_list_ths` 权限不足，因此不将开盘啦内容标注为同花顺原文。
- 每股按来源首个题材计入一个分组，保留其他关联题材。按家数、最高连板排序，组内按连板数和最后封板时间排序；缺失题材归入“题材待补充”。
- 来源记录必须为请求日期、合法代码且不重复；异常时显示来源错误，保留原涨停名单但不套用错误资料。
- 资料解析包含来源原因摘要、近30日公开公司公告、截至复盘日已披露的最近报告期业绩。公告不是自动认定的涨停诱因；财务数据按公告日期截断，零值与缺失值分开显示。
- 使用既有持久化快照队列和重试机制，不新增表。界面轮询期间切换股票、日期或范围会取消旧请求，避免显示旧响应。
- 长图导出当前筛选结果，保留完整原因和关联题材，采用当前明暗主题；来源尚未就绪或出错时禁用导出。

## 验证

后端规则测试覆盖唯一归组、过滤、零值、错误来源、公告与业绩历史日期边界、详情范围和权限。生产发布冒烟检查验证两条新接口、分组总数、详情历史边界以及未登录访问限制。
