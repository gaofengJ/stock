# 题材复盘与同花顺分类口径

入口为市场分析 → 涨停复盘。标签依次为“题材复盘、涨停明细、炸板明细、跌停明细”。无 `type` 参数时默认打开题材复盘；既有 `type=U/Z/D` 链接仍打开对应明细。复用日期、范围、行业／概念、股票搜索、连板筛选、表格、抽屉、明暗主题和 `analysis:limits` 权限。

## 唯一分类来源

- 股票行业、概念与板块筛选使用同花顺 `ths_index`、`ths_member`、`ths_daily`。个股资料、行情、涨跌停、龙虎榜、选股、板块分析使用相同的分类快照。
- 题材复盘使用同花顺官方“热点复盘”页面公开的数据 `https://ozone.10jqka.com.cn/open/api/draw_lots/v1/rank/all_tab_data`，缓存源键为 `ths_hot_review`。先查询 `list_recent_date`，仅获取其公开日期列表中的数据；未公开或需要历史访问权限时显示来源状态，不绕过访问限制。
- `tab_name` 是复盘的原始题材分组，完整保留斜杠等组合名称；`abnormal_reason` 为摘要，`detail_reason` 为逐股解析。解析以普通文本展示，保留同花顺原文的来源说明，链接官方页面。
- 题材分组不同于股票长期所属行业／概念。不能拿第一条概念、其他来源行业或解析关键词猜测复盘分组。
- 原始入库数据中的旧 `industry` 仅留作原始记录。对外列表与详情由同花顺分类覆盖；分类模块或成员数据缺失时清空旧分类。请求板块筛选但分类服务不可用时明确报错，不静默忽略筛选。
- `includeLabels=false` 的选股响应也清空分类字段；前端标签分批加载时不再回退到原始行的 `industry`。分类缓存读取校验同花顺行业／概念代码范围。
- 板块资金流使用 `moneyflow_ind_ths`／`moneyflow_cnt_ths`，投资日历的行业概念使用同花顺官方事件数据。行情、财报、公告、新闻正文不是分类数据，保持各自原有来源标注。

## 数据与展示边界

- 股票范围仍采用既有非ST涨停名单，按代码与当日同花顺复盘相交。每股只计一次；同花顺未覆盖的股票归入“题材待补充”。不使用开盘啦或其他提供方回退。
- 校验日期、代码、重复记录、分组对应关系与必需字段。空摘要保留缺失语义；异常不会覆盖已有有效缓存。旧开盘啦缓存键不再读取，无须删除历史记录。
- 分组按家数、最高连板排序，组内按连板数和最后封板时间排序；排序可能与同花顺图片不同，成员与分组一致。
- 详情展示同花顺摘要和个股解析，另列近30日公告及截至所选日期已披露的财报，不将公告自动认定为涨停原因。
- 沿用持久化快照队列、错误状态、重试与轮询；不新增数据库表。来源未就绪时禁止导出。长图导出当前筛选的同花顺题材与摘要，完整个股解析在详情查看。
