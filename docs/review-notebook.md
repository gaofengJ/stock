# 每日复盘与图文成稿

管理员在 `/review` 使用一条五步流程：市场与情绪、主线与催化、候选与风险、持仓与执行、明日计划。候选筛选和持仓工具嵌入对应步骤，不再提供重复的辅助工具 Tab。普通用户继续使用原复盘工具。

“读取当日资料”汇总大盘、均线广度、情绪、强势股反馈、板块、涨停题材、龙虎榜和资讯。各来源独立处理失败；日期不一致标记暂缺，不用别日行情替代。各步骤保留相关详情入口，财务、风险、机构研究、资金和日历按需深入。判断、实际操作及条件计划仍由用户填写。

记录仅内置管理员可访问，查询按当前用户隔离；正文接口使用 no-store。图片接口按用户鉴权，使用 private、强制重新验证的浏览器缓存，只有通过身份和归属检查后才返回 304。保存采用事务与 revision 比较，冲突返回 409，每次保存保留历史版本。旧 private/public 字段向后兼容；article 与 research 为可选扩展，不需新增迁移。旧浏览器候选与计划可明确带入私人证据栏，不能自动覆盖服务端记录。

## 图文能力

“图文成稿”默认预览，可编辑正文、从公开事实生成初稿、上传或粘贴图片、生成市场数据图、调整图注/来源/章节位置/顺序。正文、图片与资料随版本保存。完整文章可复制 HTML 或下载含图片的离线 HTML，每张图片也可单独复制/下载。目标编辑器若过滤剪贴板图片，使用逐张上传补齐；网站不能保证第三方粘贴行为。

正文最多 40000 字符，最多 20 张 PNG/JPEG 图片（上传时也可转换 WebP），每张 data URL 最多 500000 字符，图片总量最多 6000000。上传图先按尺寸压缩；SVG 和外链图片不进入渲染器。前后端均校验内容，HTML 转义用户文字。只有管理员笔记 POST 路由放宽至 8 MiB，其他路由维持原限制；部署入口代理也必须允许该路由请求体。

图文初稿仅使用公开资料和用户明确选为公开素材的文字。资料包、复制与导出均不自动包含私人持仓、成本、盈亏、执行笔记。历史图文保留旧图片；发布记录保存独立图文快照。

## Skill 交接协议

先保存版本，再下载图文资料包或复制本次任务交给 Codex。网站没有本地 Skill 执行器，不把复制任务称为自动运行。飞书目标目录和个人配置保存在本地 Skill，不提交公共仓库。

资料包格式为 `stock-review/v1`，仅包含 `schema,date,revision,article,research`；article 为 `{body,images,feishuUrl}`，images 为 `{id,data,caption,source,after}[]`。after 是正文 `##` 章节名，空字符串表示开头，失配章节的图片放到末尾。正文不要重复嵌入图片 Markdown；完整图片由 images 管理。

Skill 使用真实图片插入飞书对应章节，回读图片和真实文档链接，再导入同格式结果包。网站拒绝日期或保存版本不匹配的结果，存在未保存修改时禁用导入；导入只更新 article，私人记录保持原内容。公众号、雪球仍由用户手动发布。

## 验证

前端回归覆盖公开内容隔离、图文导出、图片校验、历史格式兼容、资料缺失和日期/版本冲突。后端测试覆盖图文解析、发布快照、账户过滤、资料日期一致性以及专用请求大小边界。账户/CSRF/隔离数据库检查沿用现有集成测试。浏览器验收覆盖上传、粘贴、排序、复制、离线下载、刷新恢复、历史图片和 Skill 回填，并检查宽窄屏的单一纵向滚动。

## 读取性能

页面使用 `publicationBodies=0&previous=0&assetReferences=1` 只读取当前正文和图片引用；按需加载原始 PNG/JPEG 图片，单次最多四个并发请求，同一图片去重。图片全部读取且校验通过后才允许编辑、保存或导出。保存和交接协议仍传完整内联图片，不接受外链或内部引用；默认 API 保持完整历史内容与图片的旧行为，历史发布正文继续单独按需读取。
