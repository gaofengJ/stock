# 私人复盘工作台

管理员在 `/review` 使用四块简版工作台：市场与主线、今日操作、明日计划、一条总结。详细研究与检查项折叠为可选。原候选和持仓工具保留，可明确带入私人证据栏；市场事实按所选日期查询，缺数据不替换其他日期。普通用户继续使用原复盘工具。

记录仅内置管理员可访问，且查询按当前用户隔离；所有接口 no-store。`ReviewNotebook1792195200000` 新建三个表，不修改行情表。保存采用事务和 revision 比较，冲突返回409；每次显式保存保留不可变历史版本。浏览器关闭与切换日期时提示未保存修改。旧草稿不会自动覆盖服务端记录，需在工具页带入并保存。

公开笔记只读取独立 public 字段，内部持仓、成本和执行不自动进入。HTML复制与下载转义原文，预览使用纯文本。模板可复制到飞书或下载HTML。网站未接入飞书OAuth或创建接口，复制不是自动创建云文档；公众号和雪球由用户手动发布，可回填对应HTTPS文章链接并存储该版本公开稿快照。没有任何自动下单或自动发布接口。

验证覆盖账户隔离、未登录和普通用户拒绝、CSRF、字段白名单、历史版本、并发保存冲突、公开字段隔离、输出HTML转义和发布快照不随后续编辑变化。数据库验证接入现有账户集成测试的隔离测试库。
