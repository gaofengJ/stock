# 每日复盘素材交接

网站记录事实、用户判断和素材；写作 Skill 在用户调用后补充分析并生成飞书图文。网站不自动调用本地 Skill，也不自动发布文章。

管理员日常流程为市场环境、主线与题材、策略选股、操作与经验。文字可留空；新旧字段与历史版本兼容。选股改动同步到本页后，由统一保存按钮写入服务端。投资日历与交易日期共用月历，显示开关不删除已选事件。

## stock-review/v2

下载入口：每日复盘 → 图文素材 → 更多 → 下载图文资料包。先保存当前版本。

- date / revision：回填必须匹配当前已保存版本，未保存修改时不允许导入。
- userNotes：显式允许的研究判断、选股记录、经验和旧计划。非空原文必须保留，另写独立的 `## AI 分析`；空白不能被解释为空仓、无交易或没有观点。
- context：大盘、指数、广度与情绪背景，仅辅助分析，不作为文章固定章节。
- research：题材与板块来源，保留 ready/missing、日期和获取时间。
- materials.links：可直接打开的取图链接及说明。Skill 仍需按日期核验并取得真实图片，最终不能用链接或占位代替图片。
- materials.calendar：用户选定的事件日期、详情与来源。未来日程不得写成已发生事实。
- materials.includeExecution：默认 false。用户明确开启才交接操作与持仓记录，仅用于私人飞书复盘。
- article：已有正文（可为空）、PNG/JPEG 图片、图注、来源、位置及真实飞书链接。
- legacyPublicNotes：旧版公开字段，保留兼容。

最终文章无需独立的通用大盘指数或明日计划章节；观察条件放在候选下面。Skill 使用用户原文和自己的分析分别组织内容，不覆盖网站原始笔记。

回填沿用相同日期和 revision，仅更新 article。v2 导入检查用户原文、AI 分析章节和已有图片完整性；日期/版本冲突时保留本地结果，重新读取对比，不能伪造 revision。v1 旧结果仍可导入。

图片上限 20 张、单张 data URL 500000 字符、合计 6000000 字符，正文 40000 字符；上传时浏览器压缩实际图片。链接和日历每类最多 40 项。历史版本保留原内容，简化页面不会删除旧计划。

K 线按当前候选筛选和排序跨页切换，支持 ↑/↓ 键。短期缓存 60 秒且最多 12 份已完成响应；相邻股票预加载、请求复用、无人使用时取消。网络或网关临时失败只重试一次，认证和数据口径错误不自动重试。
