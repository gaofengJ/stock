# 每日复盘交付

网站保留事实来源、用户记录、观察名单、四张暗色原图及保存版本；本地 `stock-review-feishu` 只读图解读、通过已授权飞书 CLI 写入和回填。网站不接入另一套模型，也不维护另一份生成文章的表单。

## 使用

1. 选择交易日，看图并加入观察。表格支持当前页全选、跨页保留、已观察筛选和标签移除；K 线弹窗可加入或移出观察并继续浏览，关闭时定位当前股票。
2. 可选填写原文和闲聊。风险、减持和最近三个已披露报告期复用策略页组件及接口；未知资料不显示为无风险。
3. 点击“准备图文资料”。只补缺少的四组图片；需要更新已保存的图时点“重新生成全部图片”。每组最多 60 秒，成功组保留，允许停止；打开历史页面不自动重新生成或修改资料。
4. 保存复盘，复制 Skill 任务。生成飞书文档后以原日期、revision、generation 导入成稿，再保存。版本冲突不能强行覆盖。原始私人字段和上传图片保留。

## 配图规格

固定宽度 1440 像素，暗色主题、不改变浏览器主题偏好。直接捕获现有平台图表，在同一 Canvas 连续拼接，组内无额外留白。每张图片最多 3000000 字符，全部图片仍最多 6000000 字符，避免变成低清缩略图。

| 组 | 原图 |
| --- | --- |
| 市场概览 | 指数相对表现、市场成交额、MA20 均线广度、60 日新高与新低；近 60 个交易日 |
| 情绪指标 | 当日涨跌分布、盘中上涨家数（近 10 个交易日）、上涨与下跌家数、涨停跌停炸板、封板炸板率、最高连板、昨日涨停股今日表现、昨日涨停股今日平均涨幅 |
| 连板分析 | 最高连板、涨停梯队数量、连板晋级率、首板与连板成交额 |
| 涨停板复盘 | 复用网站原生长图导出，全部题材和股票，不截分页 |

正文固定为声明、市场数据与三段简要解读、涨停板复盘、策略选股、可选用户原文、闲聊。策略选股仅名称与标签；闲聊不由 AI 代填；二级标题前留空段落。

## 时间与故障

本地 Skill 用 `run_budget.py` 记录阶段和 CLI 返回，正常目标 10 分钟，20 分钟停止新增调用。CLI 单次最多 90 秒，返回不明先查询，已成功步骤不重复。网站图片准备总预算最多约 4 分钟，正常数据就绪时远低于上限。

涨停复盘请求只对网络故障及 502/503/504 重试一次，每次 15 秒；不重试权限或参数错误。行情名单与资料源分离：题材或公告源异常保留行情名单，标明缺失状态。更换日期清除前一日结果；同一日期刷新失败保留此前成功结果。缺失来源不会被当作正常、零或无风险。

## 验证

`apps/front/scripts/test-notebook.cjs` 覆盖跨页选择、日期版本冲突、用户原文与执行隐私、四组图片迁移、前后端图片大小和放置规则、接口重试边界。后端 `theme-review.spec.ts` 覆盖来源失败仍保留全部名单和详情缺失状态。

本地 Skill 保存在用户配置目录，不把私人飞书目录、文档或授权配置提交到网站仓库。
