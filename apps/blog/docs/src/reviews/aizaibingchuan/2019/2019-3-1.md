# 2019-3-1复盘

作者：**爱在冰川**

## 原文内容

本复盘仅为鄙人的股市思考历程，非荐股，请勿跟票。

周五常规性瞎扯淡，详细复盘周日见。

-------------------------------------

如昨天所言

今天居然真的一根大阳。

![PDF 第 493 页配图](/imgs/aizaibingchuan/pdf/2019/be3de98436f53268238c.jpg)

昨天亏成狗，看看投票，投熊市的多啊

看看大伙都认为是熊市，然后昨晚刚把思维调换成熊市思维，

今天又被市场教育了，尾盘一看，还是“ 牛市”，回头还是得把思维切回“ 牛市”思维，天天切换来切

换去，神经已经错乱了。

又回头看了下这张

![PDF 第 494 页配图](/imgs/aizaibingchuan/pdf/2019/f62458eb05a95bfa5a4e.png)

![PDF 第 494 页配图](/imgs/aizaibingchuan/pdf/2019/7297c4e35c52f16595f2.png)

加上今天，

8个周五7个涨，

7个周一5个涨。

这么一想，准备周末好好复盘，周一满仓干进去，为了大盘上3000点，尽一份绵薄之力。

等到大趋势从高位落下来以后，再来切熊市思维了。（参考下图之前科创行情落幕时的走势，箭头

位置大概是11-23那一天凉的）

这两天由于连续亏损，

![PDF 第 495 页配图](/imgs/aizaibingchuan/pdf/2019/00b39dbb6fbee8d25363.jpg)

![PDF 第 495 页配图](/imgs/aizaibingchuan/pdf/2019/522249d3c1c574bd28f1.jpg)

今天割完两个地产股，

就休息了一天，节奏乱了就休息下。

其实昨天割完顶固就应该休息了，一般来说，大面吃起来，是会一碗接一碗的。

本来昨天休息一下，今天抄底跌停板，立刻回血回本~~

这么一总结，感觉思维上又悟道了。

再回头一想，这样的悟道已经好多回了。。

--------------------------------

今天上午11点左右的时候，看到小道消息说，这个周末又要请查配资了。

然后就看着大盘从近1%的涨幅，一路跳下来。。。心想说，小道消息的威力真是大。。。

到了下午又看到解读说，清查配资是好事，当初15年的牛就是被高位查配资弄嗝屁的，现在牛还在

低位，低位清查配资是利好~~~

日内就完成反转了，大家想着周末有利好，刷刷刷的又干上去了。。

![PDF 第 496 页配图](/imgs/aizaibingchuan/pdf/2019/f17128ded7ba9e22ca75.png)

这就是“ 牛市”里面的周五。

所以说，下面的行情都是这个套路了吗？

周五抄底，周一加仓，周二~周四卖票，周五抄底，继续循环？？？？

---------------------------------------

今天是三月的第一天，不过也是一个周五

周线8连阳了。

这种连阳。只有15年的牛市里面出现过。

在整个2月

![PDF 第 497 页配图](/imgs/aizaibingchuan/pdf/2019/8785b473ab8e96df488e.png)

沪指暴涨13.79%

深指涨了22.57%

创业板涨25.6%

平均股价涨了20%，所以这个月，大部分的人，持仓不动，应该平均赚20%

所以说？

等投完票，看看上次月中的那次投票。就知道后一个礼拜，大家是赚是亏了。。

-----------------------------------

基本就是这样，“牛市”就是要持股，暂时套了后面也能给你涨回来（仅限于趋势股，那种突然

拔地起来连板股不适用）

这也是牛市多股神的原因，因为所有的股，即使调整几天，后面还是一路涨，所以每个人推出

来的股，后面都是涨的，最后每个人都是股神

而最后，最能看出是不是牛的，还是得看趋势。

至少目前所有均线，都很健康。

![PDF 第 499 页配图](/imgs/aizaibingchuan/pdf/2019/d9a4075b756d569f6882.jpg)

等到均线都扛不住的时候，再说吧~~

-------------------------

祝周末愉快~~
