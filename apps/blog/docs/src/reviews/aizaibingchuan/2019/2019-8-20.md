闲 聊

闲聊一：

有个词叫二次发酵。。

因为这样的事情已经很久很久没有发生过了，久到大家已经忘了这个事了

深圳消息周日晚上出来的。

很多顶了一字，在收盘六十几家涨停的延时下，也有很多冲高回落吃了面。

但是昨晚还二次发酵了。

昨天的很多吃面股，今天反包了，

给了昨天无脑入场的人，一个获利的机会，

比如我昨天吃面的光锋科技，今天反包了十多个点。

比如，深桑达，茂硕电源，英威腾，等等，还蛮多的。

~~

二次发酵，

这样的事情很久没有出现过了~~

这是一个市场转暖的积极信号。

可以说，是在给九十月份的行情，打先头了~~

有一个有意思的地方是，

回顾下去年的秋季行情是怎么起来的？？

就是从当时的股权爆仓，然后深圳最早出了 纾 困 基 金的建立 ， 然 后 深圳板块爆发~~~然后开

始炒地图，那会最高炒了6板

再然后出了重组放宽，然后开始炒壳，恒立实业11板

再然后就是科创，简直就是疯狂炒作。

以去年的政策案例来看，，重组放宽的政策会比 纾 困 基 金 的政策重要吗？

显然比不上，差距太大了，

但是更小的政策反而炒的更厉害

这是为啥呢？

这就是情绪期的一步步回暖~~

卡到了秋收行情的点上

秋收行情，资金返场。

自然是炒新出的题材。

so

感觉踏空了深圳，也不要难过~~

只要行情来了，机会会多多~~~

今天市场大面股很多

10个点以上的回头波，差不多有10个股。

炸板率超过50%，，基本上今天一半的板，都炸了。

第一的是一个庄股，就没啥好说的了。

第二个的是科瑞技术，今天两次上板，尾盘收绿。应该是今天的明星票了吧。

之前写过，不知道大家还记不记得，，

大涨日之后，次日接力，尽量回避开板次新，

除非这是一个龙头，

科瑞技术是吗？显然不是。
