# 21世纪什么最重要

作者：**爱在冰川**

发布时间：2019-12-21 23:59

## 原文内容

**一：**

差不多是在15年前的现在，

贺岁档一本天下无贼上映，

主演群星荟聚，

剧中，黎叔让叶子给自己揉揉肩，

自问到：二十一世纪什么最贵？

![图片](/imgs/aizaibingchuan/2019/2247502712-1/image-01.jpg)

前一秒还享受按摩

一脸舒坦的黎叔，

突然双目圆睁

道出了惊世答案

人才！

![图片](/imgs/aizaibingchuan/2019/2247502712-1/image-02.jpg)

这句自问自答的句子，已经成为经典，流传至今。

那么为何人才最贵？

切看下去。

**二：**

![图片](/imgs/aizaibingchuan/2019/2247502712-1/image-03.webp)

这个东西叫做话筒，

上个世纪九十年代，歌厅开始盛行，彼时有个洋气的名字，叫做卡拉OK。

上个世纪九十年代，还发生了一件很重要的事情，

国有企业改制，大锅饭制度被打破，无数人国有企业工人下岗，

大部分没有能力的人，可能就是另谋出路，打工，亦或者是，摆地摊，都在改革的浪潮中，逐浪而行。

彼时在山东的潍坊，有一家厂，潍坊无线电八厂，倒闭了。

他们的产品就是做卡拉OK话筒里面的受话器，也就是我们常说的MIC。

![图片](/imgs/aizaibingchuan/2019/2247502712-1/image-04.webp)

（潍坊无线电八厂 P112型受话器 用于话筒）

卡拉OK正在兴起，行业热潮中，企业却倒闭了。

潍坊市无线电八厂的一个车间技术员，利用了八厂原来的技术，跟几个同事合伙组建了一家小私营企业，主导产品仍然是话筒。

这个技术员，名叫姜滨，

一家小小的电子元器件组装企业，后来发展成了潍坊市巨无霸的上市公司。

名字叫做歌尔股份。

一家本土企业如果在声学的领域追赶世界先进水平？

答案只有一个，挖人。

歌尔股份的HR南下很多城市，

富士康对面的酒店租个房间，就开始挖人。

对面富士康的员工，下班来面试，只要条件符合，工资直接给翻倍，直接拉去潍坊，

从研发，到质量，到制程。

富士康只是其中之一。

拥有的大量高薪挖来的人才之后，

局面显而易见，歌尔声学，以着火箭般的速度，迅速赶超国内其他的竞争对手。

在声学的领域，国内的龙头是瑞声声学（AAC）（这也是家传奇公司，能写5w字），

原本差了18条街差距，迅速拉倒只差半个身位。

2008年上市。

黎叔那句话，如此的真实。

**三：**

2008年下半年，一篇研报《歌尔声学：专注声学科技传递美好声音在》诞生，之后该股5年最大涨幅超**40倍。**

发布者为赵晓光。

而歌尔声学，则被称之为，他的封神之战。

此后，赵晓光，2010年~2015年连续6年摘得《新财富》电子行业分析师第一名，

连续6年！

2016年，赵晓光加入天风证券，

而在2016年之前，在有“券商琅琊榜”之称的新财富榜单上，天风证券一直在新财富的榜单中榜上无名。

2016年，这一年，加入天风证券的，还有

先前安信证券首席策略分析师徐彪、传媒互联网首席分析师文浩，等等。

仅是那一年（前后），就有9位新财富分析师陆续加入天风证券。

现如今，

天风研报在市场中的受追捧度，彰显了其人才聚集的价值体现。

黎叔那句话，再一次如此的真实。
