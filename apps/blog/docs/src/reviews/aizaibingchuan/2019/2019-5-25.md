# 看山还是山，看水还是水

作者：**爱在冰川**

发布时间：2019-05-25 23:54

## 原文内容

今天晚上吃饭回来晚了，木有时间更新了，就简单写一下。

昨天写到为了什么炒股，虽然答案很多，其实大部分的人核心目的都是一样的，那就是赚钱。

今天翻到我在17年初写的一篇文章，超契合昨天的话题。

宋代的青原行思大禅师说过这样一段话："老僧三十年前来参禅时，见山是山，见水是水；及至后来亲见知识，有个入处，见山不是山，见水不是水；而今得个体歇处，依然见山还是山，见水还是水。"...

![图片](/imgs/aizaibingchuan/2019/2247498092-1/image-01.jpg)

由此得来人生三个境界："看山是山，看水是水；看山不是山，看水不是水；看山还是山，看水还是水。"

转换到股市里，

回忆下你当初刚入股市的时候，有人问你：为啥买这个股？你答：感觉这个股票能赚钱吧？
“看山是山”

当你经历一段时间后，你对股市有一定认知的时候，你就会头头是道，为啥买这个股？
因为龙头战法呀，生是龙头的人，死是龙头的鬼。
因为低吸战法呀，身为男人，手抓大波。
因为XX战法。因为YY战法，因为等等。
炒股不停的在各种战法，各种指标，各种圣杯尿壶之间切换。
“看山不是山”

当合并了所有的所学，认清了所有战法的本质，洞悉了资金博弈的根本。
你再问他，为啥买这个股。
答：为了赚钱呀
“看山还是山”

我每个礼拜都会写不少干货，
举个例子，上个礼拜我写了个可转债的玩法，管用么？周一周二的时候很管用，但是周三周四周五就不管用了。
相信大部分人这会已经忘了上周6写的是啥了，

很多时候，你学了一个方法、战法、技术指标、然后会迫不及待的去试验，可能开始2把赚钱了，第三把就亏了，第四把又亏了，然后说，这个战法是垃圾战法。弃之。然后又去学新的。但是从来没有想到，是不是应该在什么样的时候用什么战法？比如今天有100多家涨停，你去买狗啃板，能不亏钱？

神雕侠侣之中，杨过所学之杂，堪称金庸小说系列之最，而他真正成为一代大侠，还是闭关之后，融汇自身所学，贯通各种战法，创出了属于自己的黯然销魂掌，出门吊打金轮股份，讲错了，金轮法王。

慕容复凭斗转星移，会天下所有之技，但是有卵用，没有一样是自己的，被吊打成傻子。

基本就是这样，

炒股的初衷很简单，就是想赚钱。

为了赚钱而炒股。祝您早日看山还是山，看水还是水。
