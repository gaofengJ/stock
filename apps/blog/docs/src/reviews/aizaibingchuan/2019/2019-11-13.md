****闲      聊****

![图片](/imgs/aizaibingchuan/2019/2247501917-1/image-02.webp)

北向资金结束了连续13日的净流入，首次出现了净流出。

今天盘中指数一度走低，也跟北向资金的持续流出有一定关系，更多的是心里承压，

讲真的，北向资金一天流入80个亿，市场也是那个样子，流入8个亿，也是那个样子，

在部分价投人群的眼里，这个就是风向标和圣杯，从有qfii开始，有很多人追逐qfii的持仓开始进行资产配置，

跑题了，

北向资金的流入流出，很多时候影响心理层面的更大一点，比如，今天尾盘北向开始拐头向上了，，然后我们的指数也拐头向上了。

![图片](/imgs/aizaibingchuan/2019/2247501917-1/image-03.webp)

因为前段时间流入的太多了，

![图片](/imgs/aizaibingchuan/2019/2247501917-1/image-04.webp)

所以会备受关注。

等回复到了每天±20亿以内的时候，这个指标就又没人看了。。

对了，看这个图表上，最近流入是持续下降的。

很多人说，是不是外资不买了，

其实应该不是，

北向资金的构成非常复杂。

里面有借道的内资，本来的港资，现在常讲的msci罗素等等资产配置的外资，等等各种资金。

一般来说，港股下跌，北向资金肯定是要流出的，

以往的经验看，都是这样的，

美股涨，港股涨，北向资金流入，我们这权重涨。

这几天港股因为某些事情，表现的很差，所以北向资金流出是很正常的，

但是这几天还是流入的，只有今天是少量流出。。

扣掉原本预期内流出的港资/借道内资，实际上，外资应该还是在持续买入中。

很多人也在质疑，为啥外资这么买，我们还这么跌。

因为本身月份也到了，

每年到了11月份的时候，都是老生常谈的时候，

都可以把去年写的再复制黏贴过来，

无非就是11月底，基金要开始结算了，

结算内部排名啊，外部排名啊，各个产品的净值啊，各个产品负责人的奖金啊，最后这个是重头戏，

也没哪个基金经理原因在最后时刻，马失前蹄，让到手的奖金跑掉。

所以很多基金也会开始抛售股票，转为现金。

![图片](/imgs/aizaibingchuan/2019/2247501917-1/image-05.webp)

从各自立场的角度讲非常合理，

外资买不买，跟我有什么关系？

跟我有关系的，不是我的奖金么？？？

~~

讲的年底的基金排名战，

以往最常用的套路无非就是，

1：拉自己的重仓股。

2：砸别人的重仓股。

把1拓展开来讲，比如还有自己的拳头产品，比如XX1号，毕竟拳头产品，要做好看，只能用XX2号，XX3号，YY1号，YY2号，等，去狂拉XX1号的重仓股。

然后你可能会说，是不是买产品只要买什么什么1号就可以了？

这个就别多想了，1号都封闭了，你怎么买的进去？

比如今天市场狂拉的科技股，部分个股，就属于此类，

再加上最近市场对机构席位的溢价很高，

机构更是对此乐此不疲，

还有券商卖方，更是一起大手拉小手。

机构游资化，也是近两年来市场的一种趋势，

谁不想赚快钱？

反正这里面的故事，多如牛毛。。

能写一本书。。

反正有人的地方，就

有江湖，有利益，

有纷争，有帮派，

有明争暗斗，有阴谋诡计，

有趁火打劫，有是非流言，

世上无如人欲险，请君且行且珍惜。
