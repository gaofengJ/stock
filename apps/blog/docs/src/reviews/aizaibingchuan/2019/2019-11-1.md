# 2019-11-1复盘

## 原文内容

本复盘仅为鄙人的股市思考历程，非荐股，请勿跟票。

周五惯例瞎扯淡，详细复盘周日见

-----------------------------------

昨天发了个投票。。

这里看上只是字面意思，

其实暗地里代表是大家对后市的看法~~

![PDF 第 3039 页配图](/imgs/aizaibingchuan/pdf/2019/0a7080df1875865409ea.png)

选外资赢的人，基本都是看多的。

选新股赢的人，基本都是看空的。

为什么要放第三个选项呢，这是专门留给墙头草用了。。。

基本可以看到，

目前市场里面，

看多的人，只是一小部分。

看空的人，同样也只是一小部分。

加起来占比才一半不到，

剩下的都是墙头草~~

这几天写到，所有的技术指标都是中性，

昨天跌一跌，就偏空头趋势，

今天以长阳线一拉，反包了昨天的跌幅，就把指标又全部修复呈多头。

回头要是再跌回来，那就会又修复成空头。

这种行情最煎熬就是这样，，

尤其是对于那60%的墙头草来说，，

跌了割不割，，涨了追不追？

比如说我，，昨天才割完。、。

今天追不追？？？

不管怎么说，今天是外资下了一城~~

国盛证券预计的是2200亿资金流入，实际上的话可能会比这个数值少一点~~

这几天已经流入了快250亿了，，

基本上这个月都差不多会是持续流入了，，

但市场杀情绪的时候，，外资流入对市场基本都没有啥影响。。

A股的一些历史规律总是不断重复

比如说，每当超大市值股票上市的时候，

![PDF 第 3042 页配图](/imgs/aizaibingchuan/pdf/2019/c228641f0429811bde9f.png)

市场总是走势会比较坑，

去年两个大盘新股上市。

市场走的都很一般。。

药明康德，工业富联，宁德时代

![PDF 第 3043 页配图](/imgs/aizaibingchuan/pdf/2019/d0ab51116b461120211f.jpg)

![PDF 第 3043 页配图](/imgs/aizaibingchuan/pdf/2019/e281f3d63a7c1dc24d42.jpg)

所以说，一整个十一月，

都将在

外资流入，与，新股抽血 的PK之中度过。。

外资流入十一月就结束了，，新股抽血的时间还，。。。。。。

-------------------

每次亏残废的时候，就不想干了，，

但是不干又得踏空，，

今天就按照计划打了数字货币的一进二，

第一个板的飞力达。。

![PDF 第 3044 页配图](/imgs/aizaibingchuan/pdf/2019/c43ad4ad7ab54a650f4c.png)

后面炸板，就开始影响心情了，

后面有些板打的有点畏畏缩缩了，，下手有点慢。。

比如说易见股份这种反包上影线必打的板，，

比如当代东方这种超低位的首板，

都没有打到。。。

下午看看指数强的不得了，，摇摆不定心感觉到了深深的 踏空

又开始排撤排撤了，，

比如说打板漫步者，，看看单子不够又撤单了。。。

最后，，一天啥也没动。。。

踏空就很难受了，

想想这个周末又要发酵什么数字货币二波啦~~~

什么tws 耳机机构持续看好啦~~~

什么外资流入坚决看好大白马啦~~~

想到这里，踏空感，感觉到更深了。。。

------------------------------

以前聊过一个话题，

就是当你对一个行业太熟悉的时候，相关股票根本不会去买。。

比如说，我干了好几年的电声行业，对这个行业太熟悉了，，

对于机构最近狂推的TWS耳机，，简直看的就是一脸懵逼，，

机构的逻辑很简单，，苹果出了新的TWS耳机，

会带动国内厂商的模仿山寨，

因为苹果的耳机太贵了，所以消费者只能买山寨的

会拉动国内各种耳机厂的业绩增长。。。

干了很多年电声行业，并且是给苹果供货的我，如何能接受这条逻辑？？？

苹果的tws 耳机基本都是立讯精密代工，

而且这里面还有很多故事，，原来的一供，不是立讯，因为原来的一供做不好这个TWS耳机，然后

才去找的立讯做的，在昆山。。

看好TWS耳机的市场，不应该就是买龙头苹果的代工厂立讯精密吗？

为啥卖方推的是各种山寨厂？机构还很买账，各种大买。

这和我们短线选手不是一样么，，龙头股不买，，大买跟风股，，大家还买的很开心？？

~~~

再比如，上个礼拜和同学吃饭，同学是格力的经销商，

聊天的股票的时候还说，格力的股票今年不能买，业绩肯定要下来的，

光是南京总代就压了40个亿的货，更不要说下面经销商压的货了。

今年都拿不动货了

（注：格力的商业模式就是经销商先交钱，再发货，所以格力的现金流好）

然后，他跟我吃完饭，这才过去了一个星期都没到。。

今天格力还特么差点涨停？

~~~

以前写过，研究股票只能研究到7分明白。

当你研究到10分明白的时候，也没股票可以买了~~

炒短线，基本研究个5分懂就可以了，，

很多时候决定股票涨不涨的时候，

名字好不好，甚至名字几个字，都比业绩重要。

-------------------------

这个星期进行了很多SB操作，，

上了深深的一课，比如说，

买深大通的二天，跌停板上没止损，看下午看区块链有所回流，从跌停板上，往上扫了4百多

万，，一根直线冲到-5%，，然后就没有然后，，

尾盘跌停板的时候，默默把前一天的割肉，，昨天再把跌停板上扫的钱，继续割了一天~~

这个就是典型的买上头了，，

第二天买多了，第三天不信邪，第四天统统割光~~~

所以说，炒股最重要的还是顺势而为，

就这样吧，

祝大家周末愉快。
