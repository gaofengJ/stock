****闲         聊****

**闲聊一：**

这一轮的美股迅速下跌之后，昨晚特郎璞怼了美储，意思就是新冠不是下跌重点，下跌的重点，依然是美储的坐视不管不理不闻不问不猜，

反正昨晚怼完美储后，美股加速上涨，

单日涨幅5%，创下了N年内的最大涨幅。

最立杆见影的是，昨晚刚怼完。

今晚美储就宣布降息，

而且是一降降了50个基点~

非常超预期

然后美股开始非常玄幻的一幕。

本来跌了-1%，一把暴涨拉升2%，拉到了1%。

然后又跌没了。

完美体现了一个思考及情绪的演变的过程。

出了降息：卧槽这是利好，干

思考了几分钟，

卧槽，这个味道不对劲了，这是北美储在常规会议之外决定降息50个基点，这特么的看起来就像是个危机啊。

然后扭头就开始跑路了。。

美国指数一把又跌下来了。、。

![图片](/imgs/aizaibingchuan/2020/2247503928-1/image-09.webp)

这个走势，太梦幻了。。。。

**闲聊二：**

聊下今天市场，

昨天情绪已经很高潮了，然后美股又大涨，

今天市场情绪更热了，

早盘就是就是涨的一脸懵逼了，

早盘上冲的时候是带量的，但是非常块的速度，就冲到3%~4%，这个就没办法玩啦~~

指数涨了7%，这个时候哪有人愿意再来追高了，然后成交量就开始缩量了。

高位缩量么，大家都懂的，后面就开始一路回落了。。。

---------

这鸟行情，我是不要说跑赢创业板了，

连主板没都没有跑赢。

这种普反格局说实话，对短线选手不是特别友好，因为没有分歧，好的买不到，买到就是坑

今天炸板炸了85个，对短线选手来说，这哪是大涨，简直是噩梦啊。

**闲聊三：**

关于大盘。

目前指数的观点还是维持之前的，这边接下来做一个区间震荡会相对比较合理。。

虽然市场量能依然保持在万亿，但是实际情况是现在是缩量的。

![图片](/imgs/aizaibingchuan/shared/9ed465a402dbf646b6818143ccc53d08d37187863e5ada1df83930a427435a12.webp)

无论指数后面是向上还是向下，都需要经历一个筹码沉淀的过程。

但是对于短线选手来说，市场有量，还是要积极参与的。

前面一段时间，成交只有四五千万的时候，天天满仓干，现在万亿成交量，反而畏手畏脚，这个肯定是不合理的。

对于很多资金来说，他们是否出手的唯一标准就是，市场成交量的大小。

短线选手还是更多的关注下情绪周期就好了。

万亿成交量下，冰点穿越的股票，真的是无限躺赢。。

上上周我冰点买的铜峰电子，躺了快一个礼拜。

上周五大冰点，怼高标的人，这两天也都是躺赢，像宏润建设什么的，连汉钟精机这种10个亿的成交量的票，都能给两个板，真的太夸张了。。

为什么说炒股要逆人性，上周五那种大跌的情况下，大部分人都是在套牢中对于是否要割肉而绝望难受。而另一边还有勇士去勇于怼高标，冲锋陷阵。

情绪转暖后，这些高标的加速，就是市场对这些勇士的奖励，也不要去太羡慕了。
