# 盘中涨跌家数

市场情绪页的“全市场盘中上涨家数”实时使用财联社全市场统计，包含 ST，
独立于页面其他盘后图表的日期和市场筛选。可查看最近 1、5、10、20、30
个已采集交易日（默认 10 个），也可指定截止日期。

生产环境默认开启，每个交易日北京时间 09:30–11:30、13:00–15:00 每 5
分钟采集一次（包含端点，最多 50 条/日）。查询现有交易日历排除节假日；
日历缺失时不猜测交易状态。只保存日期、时点、上涨家数、下跌家数及实际
采集时间及来源，最多保留最近 30 个有记录的交易日，约 1500 条。采样写入与
历史清理在同一事务中执行；MySQL 命名锁和复合主键防止多实例重复请求。

读取接口 `GET /api/analysis/market/intraday-counts?days=10&date=2026-09-30`
复用 `analysis:senti` 权限，只读数据库，不随页面刷新请求上游。前端每
分钟读取已有记录。空历史显示等待采集，跨日连续展示，缺失时点保留断线；旧时点不
补写为零，也不将休市时返回的上一交易日行情记到今天。

开关 `INTRADAY_COUNTS_ENABLED=false` 或 `SCHEDULE_ENABLED=false` 可停止
采集；开发环境默认关闭。财联社网页接口没有公布调用额度，失败或限流时
不立即重试，等待下一个 5 分钟周期。该接口只提供当前汇总；
图表记录的是采集时点，上游未提供精确行情时间戳。

## 接入前历史回补

财联社不能回查盘中历史。`ops/backfill-intraday-counts.cjs` 使用新浪或东方财富未复权
5分钟K线，按每只股票的时点收盘价与平台当日 `pre_close` 比较，汇总沪深北
A股上涨/下跌家数。市场范围复用平台规则，北交所旧代码映射后去重，逐股逐日
收盘价须与平台日线一致。每个交易日48个真实K线结束时点：09:35–11:30、
13:05–15:00，不伪造09:30/13:00。缺少K线时只有该日所有K线成交量之和
等于平台全天成交量，才能确认缺失区间无成交并沿用最后成交价；否则拒绝该股。
所有股票、所有时点完成且收盘涨跌数与全市场日线汇总一致后，才能事务写入。
实时记录优先，回补不覆盖已有记录；来源 `history_5m`，实时默认 `cls`。

请求串行、间隔至少1秒，主源每只股票请求一次最多1970条记录，校验失败才请求
东方财富历史K线备用源（同样未复权），在内存中处理后
丢弃，不保存个股分钟数据。断点文件只保存已完成代码、失败原因、日线指纹和
汇总计数，不保存分钟价格。再次执行只请求失败/未完成股票。缺失或错误不会
发布部分市场的家数。重建数据与财联社实时的统计口径可能存在细微差异，界面
和悬停提示明确区分来源。

GitHub Actions `Backfill thirty trading days of intraday breadth` 的
`workflow_dispatch` 参数为 `end_date`，如 `2026-10-03`。在已部署新版本后
启动，任务在生产服务器运行，与本地电脑息屏无关，最多重试3轮，断点保存在
`/opt/stock-release/intraday-history`。只保留最近30个交易日的图表汇总。
本地验证可执行：

```sh
node ops/backfill-intraday-counts.cjs --env .env.development --end 2026-10-03 --state .temp/history.json --max 20
```

省略 `--max` 采集全部，显式 `--write` 才写入数据库；完整性未通过时拒绝写入。
参考实现：[AKShare 新浪5分钟行情](https://github.com/akfamily/akshare/blob/main/akshare/stock/stock_zh_a_sina.py)、
[AKShare 东方财富历史分钟行情](https://github.com/akfamily/akshare/blob/main/akshare/stock_feature/stock_hist_em.py)。

来源与参考实现：
[财联社市场情绪](https://x-quote.cls.cn/v2/quote/a/stock/emotion)、
[levistock 调用代码](https://github.com/fleetinglife/levistock/blob/main/levistock/market/market_emotion_cls.py)。

## 上涨家数情绪展示

页面只绘制上涨家数，下跌家数仍保留在采集记录中。以所选交易日全部有效采样的
20%和80%分位值（线性插值）划分冰点、常规区间和沸点，包含零值，排除缺失及无效值。
分界随交易日范围和截止日期变化，拖动图内缩放不改变参照样本。少于5个有效样本
或两个分位值重合时，不强制划分极端区间。它表示区间内的相对位置，不是固定家数标准。
颜色按有效样本最小值至最大值，从绿色经主题中性色连续过渡至红色；无法划分时使用中性色。
每日收盘圆点只取15:00真实采样，缺失收盘保留断点，盘中最新值不作为当日收盘补入。
均值线按所选交易日内全部有效采样的上涨家数计算，包含零值，排除缺失值。
