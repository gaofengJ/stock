# 平台展示规范

个股名称和代码统一使用 `src/components/StockActions` 的 `StockLink`。悬停、点击或键盘激活展开“个股详情、预览K线、复制代码”菜单；各操作使用同宽图标和统一的菜单行样式。详情和K线沿用所选交易日期与带交易所后缀的身份，复制结果只含六位代码并保留前导零；复制失败提供手动复制。从列表打开K线时保留当前排序、筛选及所选日期，标题左右按钮及 ↑／↓ 切换股票，←／→ 平移一个交易日；输入框和其他弹层不响应K线快捷键。`DataTable` 自动提供来源列表，卡片和标签列表用 `navigation` 显式传入当前显示的股票。策略信号可传入既有K线回调，保留信号日与上下只导航。席位、排名趋势、资讯筛选和多日轨迹使用独立入口，不能用个股名称替代。表单选项、图表数据提示与静态导出文本保留原有展示语义。

主题集中在 `src/theme.ts`，保持粉红主色 #ff2e63、浅灰背景和白色内容面板。行情使用红涨绿跌，并显示正负号；量能变化使用放量、缩量或持平，不能直接套用涨跌含义。

- 正文和表格 14px，辅助文字 12px，页面标题 20px，区块标题 16px，主要数值 26px。统一中文系统字体和等宽数字。
- 卡片内边距 16px、圆角 6px、控件高度 32px；间距使用 8/12/16/24px。
- 管理页的 `Typography.Title` 区块标题使用 `account-section-heading`，统一 16px 字号、24px 行高和 12px 下间距。表单与后续区块保留 24px 间距；覆盖组件默认样式时使用页面范围选择器，浏览器验收核对实际间距和字号。
- 数值右对齐，名称左对齐。股票身份统一用 `StockIdentity` 展示左对齐的名称、代码两行；轨迹等操作使用独立操作列，风险标签使用独立列及更多浮层，不在身份列叠加第三行。小屏表格内部滚动，页面本身不横向溢出。
- 独立列表使用 `DataTable` 按可用视口高度展示，底部空间按容器内边距和实际分页高度计算，不为大屏设置固定高度上限。嵌入卡片和多区块表格可显式设置 `maxBodyHeight` 或 `autoHeight`；数据较少时保持内容自然高度。
- 行业／概念统一采用同花顺分类用词。行业按主营业务分类，概念按共同主题或关联特征归类；“板块”为两者统称，具体分类的搜索、列名、数量与轮动标题使用“行业”或“概念”。股票归属列统一使用“所属行业”“所属概念”。主板、创业板等市场分类称为“上市板块”。
- `src/utils/format.ts` 仅处理展示：金额、价格、点位、比例、股本及成交量保留两位；家数、次数与板数保留整数。空值和非有限值显示“—”，真实零值不能变成缺失。
- 按字段声明单位：个股日线成交额为千元，市值为万元，涨停明细和龙虎榜金额为元，市场日统计金额已是亿元。换算一次，不预先舍入计算值。
- 图表提示框也使用同一格式化函数，跨年趋势保留完整日期。历史日期更新时间读取 `status.dateUpdates[date]`，按北京时间显示。
- 加载、请求失败、尚未同步、确认无事件、筛选无结果分别展示；失败提供重试入口。快速切换条件使用 `useLatestRequest`，避免旧响应覆盖当前页面。
- 牛头像继续使用 `animal-1` 至 `animal-8` 的已有标识，保持用户绑定兼容。
- 内容区域的交互统一使用 `src/components/Interaction`：`NavigationLink`（默认导出）使用文字链接，不为每个站内链接添加箭头；`ExternalLink` 保留小号外链标记。`InteractionButton` 的 `select` 表示页内联动，`preview` 表示弹窗／抽屉，`expand` 表示展开／收起，`popover` 表示更多选项。导航菜单、面包屑、Tabs、Segmented、标准表单和提交／重试按钮保持各自语义。
- 联动入口使用浅底、尾部选中勾和 `aria-pressed`；有对应区域时设置 `aria-controls`，表格选中行使用 `interaction-selected-row`。不以无提示的整行点击承担唯一入口。跳转与联动拥有独立点击区域；密集内容避免重复的单选圆圈、描边和操作说明。指数卡片以整体选中态表达选择，不逐张重复说明。
- 预览入口使用中性文字与小眼睛图标，不加常驻边框；展开和更多项使用尾部小箭头。紧凑轨迹单元格将眼睛图标置于角落，不逐格重复“预览”文字。表内操作高度 24px，统一 4px 圆角、轻量悬停背景和键盘焦点。弹出更多项和帮助提示支持点击、键盘 Enter／空格和鼠标悬浮；避免同时配置 focus 与 click 触发。交互图标不复用红涨绿跌的含义，明暗主题均使用主题变量。
- 提示文案只解释字段定义、计算口径、操作结果和必要的数据限制。使用独立、客观的产品语言，不带入历史沟通背景、针对某次误解的澄清或与当前字段无关的话题；例如分组统计只说明纳入与排除规则。

公开首页以市场概览、策略选股、每日复盘为三个主入口，辅助工具和指南放在后续区块，避免重复功能描述。指南按任务步骤组织，工具入口使用独立的 `discovery-tool-entry` 和 `discovery-actions`，按钮间隔 12px，不紧贴说明段落。首页与登录注册页共用小牛、枫叶和图表装饰，沿用主题变量及粉红主色，小屏优先展示操作内容。公开文案不使用中点连接；游客试用文案统一读取 `auth/trial.ts`，服务端期限为首次进入工具后的 30 分钟，刷新不重置。

## Select 标签规范

字段名称常驻在控件外，选中、清空、加载和禁用时都保留。不能把 placeholder、当前选项、aria-label 或图标作为唯一的可见字段名称。

- 筛选栏、图表工具栏和列设置使用 `SelectField`，标签在左，间隔 8px，字号 14px。标签与控件作为一个整体换行，小屏允许控件收缩，避免孤立标签或页面横向溢出。
- 编辑表单和查询表单使用已有 `Form.Item label`，不再套 `SelectField`。动态配置必须提供 `label`，由 `CSearchForm` 生成表单标签。抽屉中的纵向字段使用关联的可见标签，可通过 `htmlFor` 或 `aria-labelledby` 绑定。
- 标签使用明确的字段名称，例如“市场范围”“成交状态”“日期范围”。placeholder 只表达空值含义或操作提示：可清空且清空表示不限时用“全部”，必选用“请选择”，多选或搜索可写“请选择，可多选”“输入代码或名称”。有默认值时直接展示选项，不重复塞入字段名。
- 多选的显示列、补充列在框外保留标签，框内以“已选 N 项”汇总；业务多选继续显示所选内容。默认值、选项值、清空语义、查询和存储逻辑保持不变。
- 标签通过 `htmlFor` 与 Select 的输入框 `id` 关联，表单由 Ant Design 管理关联。重复组件使用独立 ID；`aria-label` 可补充图表、行项目等上下文，但不能替代可见标签。表格内编辑允许由明确的列标题提供可见字段语义，并保留包含行名称的无障碍名称。

2026-10-18 盘点：源码中共 59 处 Select，其中 43 处独立筛选和工具栏控件统一为 `SelectField`，10 处沿用表单标签，4 处动态查询配置沿用 `CSearchForm`，2 处关注设置使用纵向关联标签。涉及基础资料、行情、日历、风险、券商推荐、市场分析及图表、涨跌停、龙虎榜、策略及研究报告、复盘、资讯、登录活动、用户、角色、日志和同步管理。共享行业／概念筛选同步覆盖全部引用页面。`test:display` 中的全源扫描防止新增 Select 退回只有 placeholder 的状态。
