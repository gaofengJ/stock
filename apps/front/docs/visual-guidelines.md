# 平台展示规范

主题集中在 `src/theme.ts`，保持粉红主色 #ff2e63、浅灰背景和白色内容面板。行情使用红涨绿跌，并显示正负号；量能变化使用放量、缩量或持平，不能直接套用涨跌含义。

- 正文和表格 14px，辅助文字 12px，页面标题 20px，区块标题 16px，主要数值 26px。统一中文系统字体和等宽数字。
- 卡片内边距 16px、圆角 6px、控件高度 32px；间距使用 8/12/16/24px。
- 数值右对齐，名称左对齐。小屏表格内部滚动，页面本身不横向溢出。
- 独立列表使用 `DataTable` 按可用视口高度展示，底部空间按容器内边距和实际分页高度计算，不为大屏设置固定高度上限。嵌入卡片和多区块表格可显式设置 `maxBodyHeight` 或 `autoHeight`；数据较少时保持内容自然高度。
- 行业／概念统一采用同花顺分类用词。行业按主营业务分类，概念按共同主题或关联特征归类；“板块”为两者统称，具体分类的搜索、列名、数量与轮动标题使用“行业”或“概念”。股票归属列统一使用“所属行业”“所属概念”。主板、创业板等市场分类称为“上市板块”。
- `src/utils/format.ts` 仅处理展示：金额、价格、点位、比例、股本及成交量保留两位；家数、次数与板数保留整数。空值和非有限值显示“—”，真实零值不能变成缺失。
- 按字段声明单位：个股日线成交额为千元，市值为万元，涨停明细和龙虎榜金额为元，市场日统计金额已是亿元。换算一次，不预先舍入计算值。
- 图表提示框也使用同一格式化函数，跨年趋势保留完整日期。历史日期更新时间读取 `status.dateUpdates[date]`，按北京时间显示。
- 加载、请求失败、尚未同步、确认无事件、筛选无结果分别展示；失败提供重试入口。快速切换条件使用 `useLatestRequest`，避免旧响应覆盖当前页面。
- 牛头像继续使用 `animal-1` 至 `animal-8` 的已有标识，保持用户绑定兼容。
- 内容区域的交互统一使用 `src/components/Interaction`：`NavigationLink`（默认导出）使用文字链接，不为每个站内链接添加箭头；`ExternalLink` 保留小号外链标记。`InteractionButton` 的 `select` 表示页内联动，`preview` 表示弹窗／抽屉，`expand` 表示展开／收起，`popover` 表示更多选项。导航菜单、面包屑、Tabs、Segmented、标准表单和提交／重试按钮保持各自语义。
- 联动入口使用浅底、尾部选中勾和 `aria-pressed`；有对应区域时设置 `aria-controls`，表格选中行使用 `interaction-selected-row`。不以无提示的整行点击承担唯一入口。跳转与联动拥有独立点击区域；密集内容避免重复的单选圆圈、描边和操作说明。指数卡片以整体选中态表达选择，不逐张重复说明。
- 预览入口使用中性文字与小眼睛图标，不加常驻边框；展开和更多项使用尾部小箭头。紧凑轨迹单元格将眼睛图标置于角落，不逐格重复“预览”文字。表内操作高度 24px，统一 4px 圆角、轻量悬停背景和键盘焦点。弹出更多项和帮助提示支持点击、键盘 Enter／空格和鼠标悬浮；避免同时配置 focus 与 click 触发。交互图标不复用红涨绿跌的含义，明暗主题均使用主题变量。
- 提示文案只解释字段定义、计算口径、操作结果和必要的数据限制。使用独立、客观的产品语言，不带入历史沟通背景、针对某次误解的澄清或与当前字段无关的话题；例如分组统计只说明纳入与排除规则。

验收：`pnpm -C apps/front run test:display`、`test:errors`、`test:market-compatibility`、`lint` 和 `build`；在 390/768/1440/1920px 下检查导航、筛选、指标卡和宽表。
